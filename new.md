# DeepDive Intelligence - Comprehensive Project Analysis Report

## 1. Project Overview
The **DeepDive Intelligence** project is a Recursive Intelligence System. It is designed to automatically ingest raw news, process it using NLP techniques, extract weak signals, build causal timelines, generate autonomous investigation goals, and synthesize human-readable Intelligence Assessments. The system operates locally and uses a modular pipeline architecture.

## 2. System Architecture
The application follows a client-server architecture.

### Backend (FastAPI)
The backend is built using FastAPI (`api/main.py`), which provides RESTful endpoints to interact with the intelligence system.
- **Database:** SQLAlchemy with SQLite (`news_intelligence.db`).
- **Core Models (`models/`):**
  - `RawNews`: Stores ingested news articles.
  - `Node` & `Edge`: Represents entities and their relationships (Knowledge Graph).
  - `Cluster`: Groups related news contextually.
  - `TimelineEvent`: Represents temporal event chains.
  - `InvestigationGoal`: Autonomous goals generated by the system to fill knowledge gaps.
  - `IntelligenceAssessment`: The final synthesized human-readable report.
  - `AssessmentQualityMetric`: Benchmarking metrics for the assessments.

### Frontend (React/Vite)
The frontend (`frontend/`) is a React application built with Vite. It serves as the dashboard to visualize:
- The overall system health and database statistics.
- The Knowledge Graph (Nodes and Edges).
- Ongoing Investigation Goals.
- The Final Intelligence Assessments.

## 3. Pipeline Modules
The heavy lifting of the intelligence system is done by a sequential pipeline of specialized modules:

1. **Ingestion (`ingestion/`)**: Fetches or manually receives raw news and stores it in the database.
2. **Preprocessing (`preprocessing/`)**: Cleans and normalizes the raw text, extracting keywords and core entities.
3. **Clustering (`clustering/`)**: Groups related news items together using TF-IDF or embedding-based similarity to identify overarching narratives.
4. **Timeline Generation (`timeline/`)**: Analyzes temporal relationships to build chronological event chains (`TimelineEvent`).
5. **Expansion & Goal Setting (`expansion/goals.py`)**: Identifies knowledge gaps and automatically spawns `InvestigationGoal`s to seek more information.
6. **Impact Analysis (`impact/`)**: Analyzes the broader geopolitical, economic, or social impacts of the events.
7. **Signal Detection (`signal_detection/`)**: Scans for weak signals (early indicators of significant future events).
8. **Intelligence Assessment Engine (`expansion/assessment.py`)**: Synthesizes all gathered data (nodes, impacts, signals) into a comprehensive `IntelligenceAssessment` with a calculated confidence score.
9. **Evaluation Engine (`evaluation/`)**: Benchmarks the system's performance, measuring metrics like Coverage, Accuracy, Actionability, and Overall Quality.
